# Scalpture Ink

Single-page site for Scalpture Ink.

## Contents

- `index.html` — bundled page (self-contained; assets embedded as base64 blobs)

## Local preview

Open `index.html` directly in a browser, or serve it:

```sh
python3 -m http.server 8080
# then visit http://localhost:8080
```

## Deploy

The repo is a static HTML page, ready for any static host (GitHub Pages, Vercel, Netlify, S3).
